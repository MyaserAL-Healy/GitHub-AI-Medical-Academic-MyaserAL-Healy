# موضوعات طبية تعليمية

## السكري

صفحة [السكري](diabetes.html) تشرح التصنيفات العامة ومسار التحضير لزيارة الطبيب دون تقديم تشخيص أو جرعات علاجية.

## قالب الموضوعات القادمة

كل موضوع جديد يجب أن يوضح:

- الفئة المستهدفة ونطاق الصفحة.
- تعريفًا مبسطًا ومراجع موثوقة.
- علامات الخطر ومتى تطلب المساعدة.
- الفحوصات التي يناقشها القارئ مع الطبيب، دون اعتبارها طلبًا طبيًا شخصيًا.
- التاريخ والمراجع وآخر مراجعة.
- رابطًا إلى الجانب التمريضي والجانب البرمجي عند اكتمالهما.
