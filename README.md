# بوابة ياسر الطبية الأكاديمية

هذه نسخة أولية ثابتة (Static) لواجهة ويب تعليمية وبحثية. أُنشئت على فرع `feat/ai-assistant-foundation` دون تغيير الفرع `main`.

## ما تم بناؤه

- صفحة ويب عربية متجاوبة.
- هوية بصرية بسيطة باسم «بوابة ياسر».
- أقسام للموضوعات الطبية والبحث والتعليم والسلامة.
- مساعد جانبي سريع يعمل بإجابات إرشادية محلية محدودة؛ ليس خدمة تشخيص أو علاج وليس متصلًا بمزوّد ذكاء اصطناعي خارجي.
- تنبيه طبي واضح في الصفحة والمساعد.
- بنية قابلة للتوسع لاحقًا إلى تطبيق فعلي وواجهة API ومراجع موثقة.

## التشغيل

افتح `index.html` في المتصفح، أو استخدم خادمًا ثابتًا محليًا مثل:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الخطوات التالية

1. إضافة صورة ياسر الأصلية في `assets/` بعد التأكد من حقوق استخدامها.
2. إضافة صفحات موضوعية بمراجع وتواريخ تحديث ومراجعة مختصين.
3. فصل واجهة المستخدم عن API آمن، مع عدم وضع مفاتيح سرية في المتصفح.
4. إضافة اختبارات وصول وأداء وفحص روابط قبل النشر.
5. ربط المشروع لاحقًا بمستودع التمريض والوثائق عبر روابط واضحة، لا عبر نسخ بيانات غير موثقة.

> المحتوى تعليمي فقط، ولا يُعد بديلاً عن الطبيب أو المستشفى أو العلاج الموصوف. لا تضع بيانات مرضى أو معلومات تعريفية في هذه الواجهة.
