# قالب الصفحة الطبية

تستخدم كل صفحة موضوعية الأقسام التالية:

1. **مقدمة قصيرة:** ما الموضوع ولماذا يهم؟
2. **التصنيفات العامة:** دون تشخيص للقارئ.
3. **الفئات الخاصة:** الأطفال، النساء، الحمل، كبار السن، أو غير ذلك عند الصلة.
4. **الأعراض وعلامات الخطر:** مع فصل الحالات العاجلة بوضوح.
5. **التقييم والفحوصات:** ما الذي يناقشه القارئ مع الطبيب، وليس قائمة أوامر شخصية.
6. **الرعاية والتمريض والتأهيل:** رابط إلى المستودع التمريضي عند توفره.
7. **المراجع:** مصدر موثوق، تاريخ آخر تحديث، ونطاق الاستخدام.
8. **المساعد:** أسئلة تعليمية محدودة مع تنبيه السلامة.

## مثال الربط

- الصفحة الطبية تشرح المفهوم والتقييم العام.
- الصفحة التمريضية تشرح مبادئ الرعاية والمتابعة التعليمية.
- صفحة الكود تشرح كيف ظهرت المعلومة وكيف يمكن اختبارها.

لا يُستخدم هذا القالب لإنشاء نظام قرار سريري آلي، ولا تُخزّن فيه بيانات شخصية أو سجلات مرضى.
