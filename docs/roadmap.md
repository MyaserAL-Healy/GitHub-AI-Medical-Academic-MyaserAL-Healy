# تحديث الواجهة

أضيفت صفحة السكري كأول مثال موضوعي قابل للتوسع. لاحقًا يمكن ربطها من الصفحة الرئيسية، ثم إضافة صفحات منفصلة للأورام، الأطفال، الحمل، القدم السكري، الغدة الدرقية، والطوارئ.

## الربط المستقبلي

- المستودع الطبي: المحتوى الطبي الأكاديمي والمراجع.
- مستودع التمريض: التقييم والرعاية والمتابعة والتأهيل.
- مستودع الكود والوثائق: مكونات الواجهة، الاختبارات، وإرشادات النشر.

لا تُنقل بيانات مرضى أو أسرار أو مفاتيح API إلى المستودعات العامة.
