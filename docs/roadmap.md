# خارطة المنصة

## النطاق الأساسي

المستودع الأول هو المصدر الرئيسي للواجهة الطبية الأكاديمية. أما `NursingKnowledgePN` فيُربط لاحقًا كمصدر معرفي تمريضي، و`acode-plugin-docs` كمصدر توثيق وتقنيات واجهة.

## حدود الإصدار الأول

- واجهة ويب ثابتة وآمنة.
- محتوى تثقيفي عام فقط.
- لا تشخيص ولا وصف أدوية ولا قرارات سريرية آلية.
- لا تخزين لبيانات المرضى.
- لا مفاتيح API داخل المستودع.

## مسارات مستقبلية

- `/topics/` للموضوعات الطبية.
- `/research/` للمراجع والملخصات الأكاديمية.
- `/nursing/` للرعاية التمريضية وإعادة التأهيل.
- `/simulations/` للمحاكاة التعليمية غير السريرية.
- `/api/` لخدمة خلفية مصادق عليها بعد تحديد مزود الخدمة وسياسة الخصوصية.

## متطلبات الجودة

كل صفحة جديدة يجب أن تحتوي على مصدر، تاريخ مراجعة، نطاق الاستخدام، وتنبيه السلامة المناسب. يجب اختبارها على الهاتف والكمبيوتر وباستخدام لوحة المفاتيح وقارئات الشاشة.
